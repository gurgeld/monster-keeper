# Batalha

Parte de [[Visão geral]].

## Decidido

- A batalha é uma simulação. O monstro decide as ações.
- O jogador só define a estratégia antes da batalha.
- A obediência depende de atributos do monstro.

- Quais atributos controlam a obediência?
