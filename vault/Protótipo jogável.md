# Protótipo jogável

Primeira versão jogável. Objetivo: testar se o loop de treino é divertido. Parte de [[Visão geral]].

## Escopo da versão 1

1. O jogador escolhe 1 dos 3 ovos ([[Raças]]).
2. O ovo choca com uma seed nova ([[Aleatoriedade determinística]]).
3. Durante **52 semanas**, o jogador escolhe 1 ação por semana ([[Treino semanal]]).
4. No fim, a tela mostra os stats finais. Objetivo: o monstro mais forte possível.

## Fora da versão 1

- Arte: o monstro aparece só como texto e números.
- Palavra, incubação, procriação, batalha, loja, exploração.
- Save.
