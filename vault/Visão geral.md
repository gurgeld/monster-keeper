# Visão geral

Jogo de criação de monstros em Godot. Inspiração: Monster Rancher 2, mas com genética realista. Não é um clone fiel.

Plataforma: exportação HTML, publicada no GitHub Pages.

## Loop principal

1. Criar monstro → [[Ovo]], [[Palavra]], [[Personalidade]] (incubação)
2. Treinar e cuidar → [[Treino semanal]]
3. Competir e explorar → [[Batalha]]
4. Criar novos monstros para progredir → [[Procriação]]

Como o jogo cresce com o tempo: [[Progressão]]. De onde vem e para onde vai o dinheiro: [[Economia]].

Versão atual: [[Protótipo jogável]].
